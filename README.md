## What is tiin_vpn app?

<p dir="ltr" style="font-size: 16px">A multi-platform proxy client based on <a href="https://github.com/SagerNet/sing-box">Sing-box</a> universal proxy tool-chain. tiin_vpn offers a wide range of capabilities, like automatic node selection, TUN mode, remote profiles etc. tiin_vpn is ad-free and open-source. With support for a wide range of protocols, it provides a secure and private way for accessing free internet.</p>
